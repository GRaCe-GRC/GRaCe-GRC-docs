# Glossary

| Term | Meaning |
|---|---|
| Control | A safeguard or practice that addresses a requirement (e.g. "MFA for admin access"). |
| Framework | A set of requirements, such as ISO 27001, SOC 2, NIST CSF or PCI DSS. |
| Control mapping | Linking one internal control to the requirements it satisfies across frameworks. |
| Evidence | An artifact proving a control operates (config snapshot, log export, ticket). |
| Continuous monitoring | Automatically checking controls on a schedule instead of only at audit time. |
| Compliance score | A computed measure of how well controls satisfy a framework. |
| Risk | Likelihood × impact of an event affecting objectives. |
